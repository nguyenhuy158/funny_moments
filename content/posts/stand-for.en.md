When you work with developers long enough, short forms show up everywhere: chat messages, PR comments, tickets, commit notes, and even source code.

Here are some common abbreviations worth remembering.

## Communication

- `FYI` = For Your Information
- `BTW` = By The Way
- `IMO` = In My Opinion
- `IMHO` = In My Humble Opinion
- `LGTM` = Looks Good To Me
- `TBH` = To Be Honest
- `AFAIK` = As Far As I Know

## Work and Process

- `ETA` = Estimated Time of Arrival
- `WIP` = Work In Progress
- `RFC` = Request For Comments
- `POC` = Proof of Concept
- `MVP` = Minimum Viable Product
- `OOTB` = Out Of The Box
- `TBD` = To Be Determined
- `FYI` often appears in issue comments when no action is required

## Programming and Systems

- `nil` = empty or null value in languages such as Go, Lua, and others
- `EOF` = End Of File
- `OOM` = Out Of Memory
- `IO` = Input / Output
- `SDK` = Software Development Kit
- `API` = Application Programming Interface
- `CLI` = Command Line Interface
- `CI` = Continuous Integration
- `CD` = Continuous Delivery or Continuous Deployment, depending on the team

## Finance and Operations

- `DPD` = Days Past Due
- `SLA` = Service Level Agreement
- `SLO` = Service Level Objective
- `KPI` = Key Performance Indicator

The exact meaning sometimes depends on the team, so when in doubt, ask once and write it down. That saves more time than pretending to understand from context.
