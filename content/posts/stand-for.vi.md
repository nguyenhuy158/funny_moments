Làm việc với developer một thời gian thì sẽ thấy rất nhiều từ viết tắt xuất hiện trong chat, comment PR, ticket, commit note, và cả source code.

Đây là một số từ viết tắt phổ biến đáng nhớ.

## Giao tiếp

- `FYI` = For Your Information
- `BTW` = By The Way
- `IMO` = In My Opinion
- `IMHO` = In My Humble Opinion
- `LGTM` = Looks Good To Me
- `TBH` = To Be Honest
- `AFAIK` = As Far As I Know

## Công việc và quy trình

- `ETA` = Estimated Time of Arrival
- `WIP` = Work In Progress
- `RFC` = Request For Comments
- `POC` = Proof of Concept
- `MVP` = Minimum Viable Product
- `OOTB` = Out Of The Box
- `TBD` = To Be Determined
- `FYI` thường xuất hiện trong comment khi chỉ muốn chia sẻ thông tin, chưa cần action

## Lập trình và hệ thống

- `nil` = giá trị rỗng hoặc null trong các ngôn ngữ như Go, Lua, ...
- `EOF` = End Of File
- `OOM` = Out Of Memory
- `IO` = Input / Output
- `SDK` = Software Development Kit
- `API` = Application Programming Interface
- `CLI` = Command Line Interface
- `CI` = Continuous Integration
- `CD` = Continuous Delivery hoặc Continuous Deployment, tùy cách team dùng

## Vận hành và nghiệp vụ

- `DPD` = Days Past Due
- `SLA` = Service Level Agreement
- `SLO` = Service Level Objective
- `KPI` = Key Performance Indicator

Nghĩa chính xác đôi khi phụ thuộc vào ngữ cảnh của team, nên nếu chưa chắc thì hỏi một lần rồi ghi lại. Cách đó tiết kiệm thời gian hơn nhiều so với việc đoán mò.
