This site is where I collect technical notes that are still useful after the task is done.

I write mostly about:

- DevOps workflows
- Linux and CLI tools
- browser and productivity tricks
- small fixes that save time later

The goal is practical documentation, not polished theory. If a note helps me solve the same problem faster in the future, it belongs here.
